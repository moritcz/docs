# Модули системы

## 1. Управление клиентами

Центральный модуль CRM — вся работа строится вокруг клиента.

### Функции
- Добавление / редактирование клиента
- Поиск по имени, телефону, email
- Фильтры: по статусу абонемента, дате регистрации
- Карточка клиента с полной историей
- Экспорт в Excel

### Карточка клиента содержит:
- Контактные данные и фото
- Текущий абонемент (тип, срок, остаток посещений)
- История абонементов
- Посещения за последний месяц
- Платежи
- Бронирования занятий
- Заметки менеджера

---

## 2. Абонементы

### Типы абонементов
| Тип | Пример | Логика |
|-----|--------|--------|
| **По времени** | "30 дней безлимит" | Действует N дней, без ограничения посещений |
| **По посещениям** | "8 занятий" | Ограничено кол-вом визитов, без ограничения по дате |
| **Комбинированный** | "12 занятий за 30 дней" | Ограничение и по времени, и по визитам |
| **Разовый** | "Разовое посещение" | 1 день, 1 посещение |

### Заморозка абонемента
- Клиент может заморозить абонемент (отпуск, болезнь)
- Устанавливается дата разморозки
- Дни заморозки не считаются в срок абонемента

### Статусы
- **active** — действующий
- **expired** — истёк
- **cancelled** — отменён

---

## 3. Расписание и бронирование

### Типы занятий
- **Групповые** — йога, пилатес, кроссфит, аэробика
- **Персональные** — индивидуальные тренировки с тренером

### Функции расписания
- Календарь на неделю/день
- Создание занятий (разовых и повторяющихся)
- Привязка к залу и тренеру
- Контроль вместимости зала
- Отмена занятия с уведомлением участников

### Бронирование
- Клиент записывается на занятие
- Проверка: есть ли свободные места
- Проверка: есть ли активный абонемент
- Статусы: confirmed → attended / cancelled

---

## 4. Тренеры

### Профиль тренера
- ФИО, фото, контакты
- Специализация (может быть несколько)
- Расписание работы
- Биография / описание

### Функции
- CRUD для тренеров
- Просмотр расписания тренера
- Статистика: кол-во занятий, кол-во клиентов

---

## 5. Посещаемость

### Учёт посещений
- Отметка прихода (check-in)
- Отметка ухода (check-out)
- Тип посещения: тренажёрный зал, групповое занятие, бассейн

### Автоматика
- При check-in: уменьшить visits_remaining в абонементе
- Предупреждение если абонемент истёк

---

## 6. Платежи

### Способы оплаты
- Наличные (cash)
- Банковская карта (card)
- Перевод (transfer)

### Функции
- Приём оплаты за абонемент
- История платежей клиента
- Контроль задолженностей
- Статусы: completed / pending / refunded
