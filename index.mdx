# FitCRM

**Современная CRM-система для фитнес-клубов** — управление клиентами, абонементами, расписанием, тренерами и платежами в одном месте.

## Для кого этот проект

Фитнес-клуб среднего размера:
- **2-5 залов** (тренажёрный, групповые занятия, бассейн и т.д.)
- **5-10 тренеров**
- **200-1000 клиентов**
