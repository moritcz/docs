# POST /api/v1/bookings

Записывает клиента на занятие. Проверяет наличие свободных мест и активного абонемента.

## Тело запроса

| Поле | Тип | Обязательное | Описание |
|------|-----|-------------|----------|
| `client_id` | uuid | да | ID клиента |
| `class_id` | uuid | да | ID занятия |

## Пример ответа (201 Created)

```json
{
  "data": {
    "id": "...",
    "client_id": "550e8400-...",
    "class_id": "...",
    "status": "confirmed",
    "created_at": "2026-03-21T14:30:00Z"
  }
}
```

## Ошибки

| Код | Описание |
|-----|----------|
| 400 | Нет свободных мест |
| 400 | У клиента нет активного абонемента |
| 409 | Клиент уже записан на это занятие |
