# GET /api/v1/classes

Возвращает список занятий с фильтрацией по дате, тренеру и залу.

## Параметры запроса

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date_from` | string | Начало периода (YYYY-MM-DD) |
| `date_to` | string | Конец периода |
| `trainer_id` | uuid | Фильтр по тренеру |
| `room_id` | uuid | Фильтр по залу |
| `type` | string | `group` или `personal` |

## Пример ответа

```json
{
  "data": [
    {
      "id": "...",
      "name": "Йога",
      "trainer": {
        "id": "...",
        "first_name": "Елена",
        "last_name": "Волкова"
      },
      "room": {
        "id": "...",
        "name": "Зал групповых занятий"
      },
      "start_time": "2026-03-22T10:00:00Z",
      "end_time": "2026-03-22T11:00:00Z",
      "max_participants": 15,
      "current_participants": 8,
      "type": "group"
    }
  ]
}
```
