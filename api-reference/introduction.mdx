# API FitCRM

REST API для управления данными фитнес-клуба. API реализовано через Supabase + Next.js API Routes.

## Базовый URL

```
https://your-domain.com/api/v1
```

## Аутентификация

Все запросы требуют JWT-токен в заголовке:

```
Authorization: Bearer <your-jwt-token>
```

Токен получается при авторизации через Supabase Auth.

## Формат ответов

Успешный ответ:

```json
{
  "data": [...],
  "count": 42,
  "page": 1,
  "per_page": 20
}
```

Ошибка:

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Клиент не найден"
  }
}
```

## Ресурсы API

| Ресурс | Описание |
|--------|----------|
| `/api/v1/clients` | Управление клиентами |
| `/api/v1/membership-types` | Типы абонементов |
| `/api/v1/client-memberships` | Абонементы клиентов |
| `/api/v1/trainers` | Тренеры |
| `/api/v1/classes` | Занятия |
| `/api/v1/bookings` | Бронирования |
| `/api/v1/attendance` | Посещаемость |
| `/api/v1/payments` | Платежи |
| `/api/v1/rooms` | Залы |

## HTTP-методы

| Метод | Описание |
|-------|----------|
| `GET` | Получение данных |
| `POST` | Создание записи |
| `PATCH` | Обновление записи |
| `DELETE` | Удаление записи |

## Пагинация

```
GET /api/v1/clients?page=1&per_page=20
```

## Фильтрация

```
GET /api/v1/clients?status=active&search=Иван
```

## Сортировка

```
GET /api/v1/clients?sort=created_at&order=desc
```
