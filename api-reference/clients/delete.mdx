# DELETE /api/v1/clients/:id

Удаляет клиента и все связанные данные (абонементы, бронирования, платежи).

<Warning>
Это действие необратимо. Все данные клиента будут удалены.
</Warning>

## Пример запроса

```bash
curl -X DELETE "https://your-domain.com/api/v1/clients/550e8400-..." \
  -H "Authorization: Bearer <token>"
```

## Ответ (204 No Content)

Пустой ответ при успешном удалении.

## Ошибки

| Код | Описание |
|-----|----------|
| 404 | Клиент не найден |
