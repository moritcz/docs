# GET /api/v1/clients

Возвращает список клиентов с поддержкой поиска, фильтрации и пагинации.

## Параметры запроса

| Параметр | Тип | Описание |
|----------|-----|----------|
| `search` | string | Поиск по имени, фамилии или телефону |
| `status` | string | Фильтр по статусу абонемента: `active`, `expired`, `none` |
| `page` | int | Номер страницы (по умолчанию 1) |
| `per_page` | int | Записей на странице (по умолчанию 20, макс. 100) |
| `sort` | string | Поле сортировки: `created_at`, `last_name`, `last_visit` |
| `order` | string | Направление: `asc` или `desc` |

## Пример запроса

```bash
curl -X GET "https://your-domain.com/api/v1/clients?search=Иван&status=active&page=1" \
  -H "Authorization: Bearer <token>"
```
