# GET /api/v1/clients/:id

Возвращает полную информацию о клиенте, включая текущий абонемент, последние посещения и платежи.

## Параметры пути

| Параметр | Тип | Описание |
|----------|-----|----------|
| `id` | uuid | ID клиента |
