# GET /api/v1/trainers

Возвращает список тренеров клуба.

## Параметры запроса

| Параметр | Тип | Описание |
|----------|-----|----------|
| `is_active` | boolean | Только активные тренеры |
| `specialization` | string | Фильтр по специализации |
