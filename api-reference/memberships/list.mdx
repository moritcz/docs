# GET /api/v1/membership-types

Возвращает список типов абонементов, которые предлагает клуб.

## Параметры запроса

| Параметр | Тип | Описание |
|----------|-----|----------|
| `is_active` | boolean | Только активные (продающиеся) абонементы |
